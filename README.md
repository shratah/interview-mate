## 📌 Overview

Interview Mate is a web application that helps students practice for internship interviews through realistic mock interview sessions. It features a complete user flow from signup to interview practice with progress tracking.

## ✨ Features

- 🔐 **User Authentication** — Signup and login with session persistence
- 📝 **Smart Onboarding** — One-time profile setup with career details
- 👤 **Profile Management** — Edit profile anytime from dashboard
- 🎯 **Mock Interviews** — Practice with 5 interview questions
- 🎙️ **Voice Input** — Answer using voice or keyboard
- 📊 **Progress Tracking** — Visual progress bar during interview
- 📱 **Responsive Design** — Works on desktop and mobile
- 🎨 **Modern UI** — Beautiful gradients and smooth animations

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/shratah/interview-mate.git
cd interview-mate

# Install dependencies
npm install

# Start development server
npm start
